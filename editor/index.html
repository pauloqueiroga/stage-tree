How to edit

  • Drag node → node to link them
  • Click to select, Enter to add a child
  • Double-click empty space for a new node
  • Del removes the selection
  • Drag the background to pan, wheel to zoom

Positions are computed, not stored: the CSV has no coordinate columns, so the layout is derived the same way tree-from-csv derives it.
