# Stage Tree Diagram

Stage Tree Diagrams are tree or graph representations to describe evolutionary processes and outcomes that have discrete stages that are typically sequential and directional in nature.

## Backlog

Planned and considered work is tracked in [`TASK-BOARD.md`](TASK-BOARD.md), not in GitHub Issues. Check it before starting new work, and update it as part of the same commit/PR when you pick something up or finish it.

### Nodes
