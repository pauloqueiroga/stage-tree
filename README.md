# Stage Tree Diagram

Stage Tree Diagrams are tree or graph representations to describe evolutionary processes and outcomes that have discrete stages that are typically sequential and directional in nature.

## Tools

- [`editor/`](editor/readme.md) — a WYSIWYG editor for building stage tree diagrams in the browser and saving them as CSV. No dependencies, no build step.
- [`tree-from-csv/`](tree-from-csv/readme.md) — a CLI that turns a stage-tree CSV into a Drawio (mxGraph) file.
